تحلیل و عیب‌یابی سامانه خرید بلیت حمل‌ونقل عمومی
در این تحلیل، سامانه را از دید یک تحلیلگر سیستم بررسی می‌کنیم. هدف این است که علاوه بر شناسایی ایرادهای احتمالی، ارتباط بین بخش‌های مختلف کسب‌وکار مشخص شود و خروجی‌ها قابلیت تبدیل شدن به مستندات فنی را داشته باشند.

سامانه شامل خرید بلیت اتوبوس و مترو، رزرو صندلی، مدیریت کارت اعتباری، شارژ کارت، مشاهده برنامه حرکت و مدیریت اشتراک‌ها است.
چالش ۱: Sequence Diagram
سناریوی اصلی از ورود کاربر شروع می‌شود. کاربر مسیر و زمان حرکت را انتخاب می‌کند. سیستم ظرفیت وسیله نقلیه را بررسی کرده و در صورت وجود ظرفیت، صندلی را موقتاً رزرو می‌کند.

سپس کاربر اطلاعات خرید را تأیید و پرداخت را انجام می‌دهد. پس از تأیید پرداخت، بلیت نهایی صادر و کد رهگیری برای کاربر ارسال می‌شود.

نکته مهم این است که اگر پرداخت ناموفق باشد یا زمان رزرو موقت تمام شود، صندلی باید آزاد شود تا امکان خرید برای کاربران دیگر وجود داشته باشد. همچنین نباید صدور بلیت قبل از تأیید قطعی پرداخت انجام شود.

اجزای نمودار:
- User
- Authentication Service
- Schedule Service
- Reservation Service
- Payment Gateway
- Ticket Service
- Notification Service

هر کاربر می‌تواند چند کارت بلیت داشته باشد و هر کارت شامل چندین تراکنش شارژ یا پرداخت است. همچنین هر کاربر می‌تواند چند اشتراک در بازه‌های زمانی مختلف داشته باشد.

ارتباط کلاس‌ها باید به‌گونه‌ای طراحی شود که تاریخچه تراکنش‌ها و اشتراک‌های قبلی حذف نشوند و وضعیت فعلی هر کارت یا اشتراک قابل تشخیص باشد.

چالش ۵: Intermediate SQL
کوئری اول: محاسبه میزان فروش بلیت به تفکیک نوع وسیله نقلیه
SELECT
    t.TransportType,
    COUNT(tk.Id) AS TicketCount,
    SUM(tk.Price) AS TotalSales
FROM Tickets tk
INNER JOIN Trips tr ON tk.TripId = tr.Id
INNER JOIN TransportVehicles t ON tr.VehicleId = t.Id
WHERE tk.Status = 'Paid'
GROUP BY t.TransportType;


کوئری دوم: شناسایی کاربران دارای اشتراک فعال و مجموع پرداختی آن‌ها
SELECT
    u.Id,
    u.FullName,
    COUNT(us.Id) AS ActiveSubscriptions,
    SUM(s.Price) AS TotalAmount
FROM Users u
INNER JOIN UserSubscriptions us ON u.Id = us.UserId
INNER JOIN Subscriptions s ON us.SubscriptionId = s.Id
WHERE us.Status = 'Active'
AND us.EndDate >= CURRENT_DATE
AND u.Id IN (
    SELECT UserId
    FROM UserSubscriptions
    WHERE Status = 'Active'
)
GROUP BY u.Id, u.FullName;


جمع‌بندی
در این پروژه باید علاوه بر طراحی صحیح ساختار سیستم، ارتباط بین کاربران، اپراتورها، پرداخت و مدیریت سفرها نیز به‌درستی مشخص شود. استفاده از نمودارهای Sequence و Class، تحلیل SWOT، نقشه ذی‌نفعان و کوئری‌های تحلیلی SQL کمک می‌کند نقاط ضعف سیستم شناسایی شده و سامانه‌ای قابل توسعه، امن و پایدار طراحی شود.

نکته: نام جدول‌ها و فیلدهای SQL فرضی هستند و باید با ساختار واقعی پایگاه داده تطبیق داده شوند. همچنین در نسخه نهایی نمودارها باید در فایل‌های Draw.io ترسیم شوند.
